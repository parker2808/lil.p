    Audit

    Map modules, owners and dead code.

    Tokens & primitives

    Shared UI base and conventions first.

  3. 03

    Strangler routes

    Move one route or module at a time.

    Contract tests

    Lock behaviour with data before cutting.

  5. 05

    Cut over

    Remove the legacy tree.
