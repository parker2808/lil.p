Foundations · R1 tokens

One type system, two palettes, one radius ladder.

Public site: “Ink & Signal”. Admin: the interview-fe KB teal. Both use IBM Plex Sans + IBM Plex Mono, the same spacing, motion and radius tokens, and the same shadcn variable names, so packages/ui components render in either scope.

Color

Public text pairs meet WCAG AA at body size; --signal is for fills, marks and large type, --signal-ink for links and small text. Admin tokens are the KB values, except --ink-faint, which is darkened to 4.6:1 because it is used for 11px group labels.

Type · IBM Plex Sans + Plex Mono

Variable Plex Sans (wght 100–700, wdth 85–100) gives a condensed display cut without a second family. Both families load the vietnamese subset through next/font. Under :lang(vi) the display leading opens from 0.94 to 1.06 so stacked marks (Ở, Ẫ, Ữ) never touch the line above, and line masks pad 0.06em so marks are not clipped.

Radius · 10px base, scaled by size

Like Apple's system shapes: small controls get small radii, large surfaces larger ones, capsules stay fully round. Where corner-shape: squircle is supported, every step is multiplied by --k: 1.5 because a continuous corner reads smaller than a circular arc of the same value.

Elevation

Hairlines first. Shadows only for things that float: menus, the palette, sticky stacked cards. The public signature hover is a hard “print offset”, never a blur.

Motion

Durations in five steps; one ease shared with the admin (the KB --ease). Everything collapses to near-instant under prefers-reduced-motion, and decorative loops stop.
