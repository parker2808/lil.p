01Problem

The v1 investor app was a Vue 2 tree with global event buses and no tests. Every release broke a form somewhere, and the team could not stop shipping for a rewrite.

02Constraints

  • Ratings for 20+ asset classes had to stay online.
  • Two developers on the frontend, one designer part time.
  • No feature freeze longer than one sprint.

03Approach

We put Nuxt 3 in front and proxied unknown routes to v1. Each sprint moved one route group, behind contract tests that pinned the API shape.

DecisionStrangler over big-bang: a slower start, but the app shipped every week.
// nuxt.config.ts — legacy fallback
export default defineNuxtConfig({
  routeRules: { '/legacy/**': { proxy: 'https://v1.internal/**' } },
})

04Decisions

Server state is not app state. Moving it to TanStack Query removed half of our store.

05Outcome

v2 replaced v1 fully after six months. The numbers above are from the last two weeks before cut-over.

06Lessons

Write the conventions down before the second developer joins. A STRUCTURE.md beat every review thread.
