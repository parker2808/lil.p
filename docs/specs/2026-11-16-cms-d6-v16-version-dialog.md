After a separate unpublished edit, the test opens Version history by Tab/Enter, checks the Restore confirmation's alertdialog name, warning, modality, trapped forward/reverse focus, Escape and Cancel focus return, and zero WCAG 2/2.1/2.2 A/AA axe violations. The spec is registered in the five-shard manifest; attach actual CI run/head before calling this automated subset proven.

**Limitations:** The D6 Publish action is an immediate button, **not a confirmation dialog**; this test checks its keyboard activation and announcement but cannot prove a nonexistent publish dialog. Manual VoiceOver and NVDA listening, spoken-announcement timing, public-page heading order, and full route/state contrast are separate V16 GAPs. Neither axe nor ARIA DOM assertions replace a real screen-reader signoff. Keep V16 OPEN in the combined matrix until those checks have independent evidence; do not infer a PASS from this PR's CI.
