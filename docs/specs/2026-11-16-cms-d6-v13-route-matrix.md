# V13 EN/VI route and state capture inventory

Description contract: the ten public/preview content routes per locale require a nonempty tag; admin and missing-page states intentionally omit the tag and record null in the inventory.

The registered `cms-d6-v13-route-matrix.spec.ts` visits five real public routes in both EN and VI, both published and authenticated draft mode, and checks SSR response status, page language, nonempty description, distinct titles within each locale/state and OG image. The demo home title is identical in EN/VI, so its localized descriptions are compared instead. It additionally checks localized public 404/noindex and recovery navigation, then visits the home/about admin editors, a created custom-page builder (strict HTTP 200 and localized region heading at desktop width) and localized admin 404/recovery in both admin cookie locales. Run `43803678290` showed the builder region was painted even while the proxy's missing `builder` section returned HTTP 404; the proxy allowlist now includes the E2E-gated builder, without allowing unknown admin sections. Every visited tuple has a viewport screenshot attached to its Playwright case, indexed by `v13-route-state-inventory.json` with route, locale, state, title, description (nullable for 404/admin pages without that tag) and attachment name. The two inventory files and 30 PNGs are generated by CI, not committed snapshots.

Existing `metadata.spec.ts` supplies real API historical draft/public title and description assertions in EN/VI, no-SEO tree H1 fallback (four additional public/preview captures), and sanitized/localized invalid-block preview help (two additional captures) versus published content. `admin-vi-editors.spec.ts`, `admin-locale.spec.ts`, `ux-404.spec.ts` and the builder design suite cover field labels, locale cookie SSR, error/help text and builder state captures. The new matrix does not substitute for independent review of raw CI attachments, exhaustive editor validation/conflict captures, manual screen-reader inspection or production parity. Score V13 only after reviewing the exact-head inventory and complementary assertions; do not infer PASS from a green test alone.
