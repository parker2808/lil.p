# B6 — host-configurable React extraction

**DRAFT — U3 design and B4 accepted; pending B6 implementation, B7 and coordinator review.** This specifies the React `./react` surface after accepted B4 `8c448ea` (PR #185); it does not add the D-phase canvas/tree builder. Read alongside [B5 engine](./2026-11-10-cms-core-b5-engine-draft.md) and the [ADR](./2026-11-10-cms-core-adr.md). B6 can run beside B5 only if it uses B4 contracts and does not import B5 internals before integration.

**Accepted B4 baseline (read at `8c448ea`):** `packages/cms-core/src/contracts.ts` exports `BlockDefinition`, `defineBlock`, `createRegistry`, `isBlockAllowedOnPage`, `localeSchema`, `pageKeySchema`, `layoutPresetSchema`, `blockSurfaceSchema`, generic block/page/snapshot schemas and types. The host assembles 20 definitions in `packages/contracts/src/blocks/block-registry.constant.ts`, and narrows the generic public `type: string` to its finite `blockTypeSchema` in `packages/contracts/src/blocks/block.schema.ts`; `packages/contracts/src/pages/pages.schema.ts` keeps host HTTP schemas. `packages/cms-core/src/react.ts` is currently `'use client'; export {}`. `packages/cms-core/package.json` already exposes built ESM, CJS and types for `./contracts`, `./engine` and `./react`; `packages/cms-core/test/exports.test.mjs` verifies import/require resolution and the client directive. Do not import host definitions into core or confuse B4's empty React entry with a shipped renderer.

## Plan (8 lines)

1. Confirm B4 registry types, U3 designs and B1 web goldens.
2. Freeze current renderer/form/keyboard behavior in isolated fixtures.
3. Extract server-safe renderer dispatch into `./react/server`.
4. Extract schema fields, widget registration and metadata contracts.
5. Pass messages, capabilities, renderers and style hooks from host adapters.
6. Verify server entry lacks `"use client"`, client entry keeps it, and SSR markup is unchanged.
7. Re-measure B3 gzip budgets and verify localized accessibility.
8. Document rollback and findings before B7 review.
