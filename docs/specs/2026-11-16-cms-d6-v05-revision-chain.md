# V05 editor → revision → render evidence

The new `cms-d6-v05-revision-chain.spec.ts` creates a disposable custom page, inserts a page-header from the real builder palette and changes two localized nested Properties (`title` and `eyebrow`) for EN and VI. Every change must appear in the real draft GET before the next edit. The final draft revision must advance; UI Publish must return version 1, and its immutable snapshot tree must equal that exact saved tree.

For EN and VI, the published API tree and authenticated version-preview API must match the saved tree. The 22 browser captures at 390, 768 and 1440 include the selected Properties inspector (top and scrolled title field on mobile/tablet) and paired public/version-preview H1 and eyebrow. The public and preview main markup must agree at each width. CI attachments include the draft revision, published version, source head and screenshot digests.

The focused page-header subset proves edited values reach a saved version and both render paths. It does **not** certify all host schemas, every validation/error state, dark-theme design approval, or production rollout. Retain those as GAP until their own reviewed evidence is available. Run with `ready-e2e` and inspect the exact-head CI attachments before claiming PASS.

The four pinned `cms-editor-host-{1,2,3,4}.spec.ts` groups now extend that chain across all 20 registry types, five per shard. For each type the real palette and Properties produce an autosaved EN/VI draft (or the valid toggle for the two browser types), and the editor captures verify the draft remains unchanged. Publishing uses that exact revision; version 1's immutable snapshot and both public and historical-preview API trees must equal it. At each locale and theme, public and preview routes must render the independently resolved host-props hash and applicable visible edit. Each type attaches 24 public/preview PNGs at 390/768/1440 and a manifest containing source head, checkout head, run ID, revision, version, tree digest and per-image digest. Dark/light is checked on the rendered document. The pre-publish builder gallery additionally supplies eight EN/VI × light/dark × 390/1440 canvas and four mobile Properties-sheet captures per type.
