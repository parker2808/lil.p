# P6-1 T31 Admin information architecture

Plan:

1. Replace the sidebar with Overview, Content, Pages, Inbox, and Settings.
2. Keep Home, About, and Contact as page layouts; put About content in URL-backed tabs.
3. Keep Tags with Posts, and redirect legacy section and experience editor URLs.
4. Add a nav unit guard and browser coverage for legacy routes and tab history.
5. Run focused tests and the full repository check before opening one PR.

The About layout remains the block editor. Its content tabs reuse the existing CMS views and APIs. Existing section links redirect temporarily to the corresponding tab. Experience editor links use nested About routes. The sidebar retains role filtering for Inbox, Users, and Audit.
