   host and four non-H1 hosts, partitioning the entire 20-definition registry.

   hidden React segment which only client-side insertion scripts exposed. Keep
   the existing route-specific loading skeletons, but do not gate the entire
   public shell behind a fallback that hides custom pages from no-script clients.

   and authenticated version preview at 390/768/1440. Check all five host
   wrappers, nonempty nested SSR content for each host with configured output,
   the explicitly empty resume state, matching preview/public text and props

   of horizontal overflow at three widths, not each host's responsive override.
   `cms-d6-parity-matrix.spec.ts` asserts explicit mobile/tablet/desktop heading
   and paragraph overrides and pixel parity, while `cms-builder-persistence.e2e-spec.ts`
   asserts publish/restore pointer and immutable version invariants. V06's full
   all-host responsive override and human visual approval remain GAP.
3. Attach full-page PNGs and a six-tuple manifest per locale/group, with source
   PR SHA, checkout SHA, Actions run, screenshot digest, width and route. Review
   the exact-head report alongside the existing V06 responsive override and
   20-host visual/axe reports before declaring responsive signoff. An empty CV
   is not evidence of a visible download; manual visual review remains explicit.
