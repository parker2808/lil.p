# D5 builder history gate — V07

The D5 builder exposes **Duplicate / Nhân bản** for a selected node in the canvas toolbar and selection strip. The command allocates fresh IDs for every descendant, then the core validates the full copy against slot/size bounds before recording one atomic history entry. Invalid IDs or exceeded limits leave history and the tree unchanged. The buttons are keyboard-accessible and labelled in EN/VI.

The focused adapter unit test checks nested fresh IDs, atomic undo/redo and a rejected collision. `apps/web/e2e/cms-builder-history.spec.ts` creates an authenticated tree draft against the real API, edits the heading, duplicates it, moves the copy, undoes and redoes both actions, waits for acknowledged persistence and verifies reloaded IDs/order and a reset history. The spec is listed in `apps/web/e2e/shards.ts` and requires exact-head `ready-e2e` CI before V07 can be marked PASS. No local browser or database without the shared lock.
