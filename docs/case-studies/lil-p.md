  - Media: Cloudinary (metadata in `Media`; no API disk writes).

- Auth: two JWT secrets, argon2id passwords, CSRF via `Origin` check. Production cookies `SameSite=None; Secure` when `CROSS_SITE_COOKIES=1`.
- Privacy: real email / phone never committed; seeds use `<email>` / `<phone>`. `pnpm check:content` fails the build otherwise.
