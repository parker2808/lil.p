Manual (this environment):

- Keyboard: public skip link was already first tab stop (T14). Admin had no skip target.
- Screen reader: not run on a real AT here. Landmark structure is `SkipLink` → `header` → `main#content` → `footer` on public pages; admin now matches.
- Page builder: Space / arrows / Space already wired through `@dnd-kit` `KeyboardSensor`; move up/down menus remain. Drag handle is a tab stop (`Drag to reorder`).
- Reduced motion: orbs stop; marquee becomes a static wrapped row (`data-static`). Reduced transparency already hides `.orb` and solidifies `--card-glass`.

## Fixes in this PR

- Public and admin skip links; `main#content` is focusable (`tabIndex={-1}`).
- Admin document title (`Admin` / `%s · Admin`).
- Stat tiles use `role="group"` so the final value can stay in `aria-label` during count-up.
- Command palette names include the visible ⌘K text; tech filter and inbox use their visible text as the name.
- Locale switcher is a pressed-button group, not a Radix tablist without panels.
- Hero `Reveal` is `eager` so the LCP headline is visible on first paint (no opacity-0).
- Case study / featured covers: `fetchPriority`, reserved `aspect-ratio`, `width` / `height`.
- Orbs sit on a composited layer (`translate3d` + `will-change: transform`).
- Count-up already reserved width with `tabular-nums` + `minWidth`; stat labels use `text-muted-foreground` so they pass contrast on `--band`.
- About availability chip uses the primary badge (success-on-subtle was 4.46:1).

## Reduced motion / transparency checklist

| Effect                   | Fallback                                                       |
| ------------------------ | -------------------------------------------------------------- |
| Orb float                | `animation: none`; hidden under `prefers-reduced-transparency` |
| Marquee                  | Static wrapped row, no duplicate track                         |
| Reveal                   | Immediate opacity 1 / translate 0                              |
| Stat count-up            | Final value from the first frame                               |
| Diagram pulse / icon bob | CSS `animation: none`                                          |
| Card glass               | `--card-glass` → solid `--card`                                |
